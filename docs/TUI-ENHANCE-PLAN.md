# TUI 增强计划（TUI-ENHANCE-PLAN）—— 以 Zotero / KOReader 为标杆

> 目标：把 Anote TUI 增强到**可以完美取代 GUI** 的易用度。
> 方法：先解剖两大标杆软件的 GUI 元素 → 差距分析 → 分支计划供选择。

## 一、Zotero 的 GUI 元素解剖（文献管理标杆）

| 区域 | 元素 | 功能 |
|------|------|------|
| **左栏（导航）** | 我的文库 / 收藏夹集合 / 已保存搜索 / 标签选择器 | 按集合、标签、搜索条件组织文献 |
| **中栏（条目列表）** | 多列表格（标题/作者/日期/类型/标签/附件），点列头排序，顶部搜索框 | 浏览/排序/全文搜索 |
| **右栏（详情面板）** | 元数据表单（标题/作者/DOI/URL/日期）、**笔记**、**标签**、**相关条目**、**附件** | 查看/编辑一切 |
| **工具栏** | 添加条目、新建集合、同步、搜索 | 快捷操作 |
| **内置 PDF 阅读器** | 高亮/批注/注释/大纲 | 精读标注 |
| **上下文菜单/多选** | 右键动作、批量拖拽到集合、批量改标签 | 批量管理 |
| **同步/设置** | 账户同步、偏好设置 | 全局配置 |

**Anote TUI 已有**：docs list（表格+过滤）、check、import、tag（registry 字段）——但缺：**左栏集合视图、右栏详情面板、多选批量、内置搜索框**。

## 二、KOReader 的 GUI 元素解剖（阅读标杆）

| 区域 | 元素 | 功能 |
|------|------|------|
| **书库/书架** | 最近阅读、按作者/系列浏览、书架管理 | 找书 |
| **文件浏览器** | 目录树、搜索 | 定位文件 |
| **阅读视图** | 分页/滚动、字体/边距设置、**阅读进度条（上下）**、章节 TOC、字典（长按）、书签/高亮/注释 | 沉浸阅读 |
| **进度保存** | 自动记录位置，续读提示 | 无缝续读 |
| **阅读统计** | 阅读时间、日历热力图、读完书目、当日进度 | 学习分析 |
| **手势/快捷键** | 点击区域映射、翻页手势 | 操作效率 |
| **夜间模式/主题** | 深浅色切换 | 护眼 |

**Anote TUI 已有**：read（读即登记）、docs progress（手动）、主题系统——但缺：**内置阅读视图、自动进度、书签/高亮、TOC、阅读统计**。

## 三、差距总表（Anote TUI → 目标）

| 维度 | 标杆元素 | Anote 现状 | 差距 |
|------|----------|-----------|------|
| 导航 | 左栏集合/标签 | 无 | 🔴 需新增 |
| 浏览 | 多列表格+排序 | docs list（表格，无 TUI 内交互排序） | 🟡 增强 |
| 详情 | 右栏元数据/笔记/标签 | 无 | 🔴 需新增 |
| 检索 | 顶部全文搜索 | 命令式 ask（Ctrl+F 页） | 🟡 增强 |
| 多选批量 | 批量标记/标签 | 无 | 🟡 增强 |
| 阅读视图 | 分页+进度条+TOC+书签 | 无（靠外部阅读器） | 🔴 需新增 |
| 进度 | 自动记录续读 | 手动 progress | 🟡 增强 |
| 统计 | 阅读时间/日历 | 无 | 🔴 需新增 |
| 主题 | 夜间模式 | 6 主题已有 | 🟢 够用 |
| 帮助 | 快捷键速查 | 已有 F1 | 🟢 够用 |

## 四、计划分支（供选择，可组合）

### 分支 A：文档管理增强（Zotero 式）—— 约 3-4 天
| 子项 | 内容 |
|------|------|
| A1 左栏导航 | 新"文档库"页：左栏=状态/类型/标签过滤器树；中栏=registry 表格（点列头排序）；右栏=选中条目详情（元数据可编辑/标签/笔记/进度） |
| A2 多选批量 | 表格支持多选（空格标记），批量改状态/标签/删除 |
| A3 内嵌搜索 | 页顶搜索框：即时过滤 registry + 全文检索（rg/混合）结果混排 |
| A4 导入/去重 | 导入按钮（docs import）+ 重复提示 |

### 分支 B：阅读器增强（KOReader 式）—— 约 4-5 天
| 子项 | 内容 |
|------|------|
| B1 内置阅读视图 | 新"阅读"页：读 `pdfs/*.txt`/`ebooks/*.txt`/笔记纯文本，分页滚动（j/k），**顶部/底部进度条**，字号调整 |
| B2 自动进度 | 退出阅读页自动写 `docs progress`（按翻页比例）；下次打开续读提示（已有 read 提示，增强为自动） |
| B3 书签/高亮 | 行级书签（存行号到 registry 或 docs/bookmarks.md）；阅读页可跳书签 |
| B4 目录 TOC | 文本章节识别（\section/标题行）→ 目录跳转 |
| B5 阅读统计 | docs stats 扩展：本周翻页/读完数/未读堆积；周报并入阅读统计 |
| B6 外部联动 | zathura/foliate 打开外部阅读器时自动登记进度（时间戳） |

### 分支 C：全局体验（导航/效率）—— 约 2 天
| 子项 | 内容 |
|------|------|
| C1 统一命令面板增强 | Ctrl+P 加"文档操作"动作（docs list/add/progress/stats） |
| C2 全局搜索 | 任一页 Ctrl+F 可搜 registry+笔记+PDF 文本，结果可跳转 |
| C3 状态栏 | 底部显示当前页统计（如文档库页：总数/在读/未读%） |
| C4 快捷键统一 | 全局 h/j/k/l 导航 + 各页 F 键约定，写入帮助 |

### 分支 D：数据与服务（支撑层）—— 约 1-2 天
| 子项 | 内容 |
|------|------|
| D1 docs 服务扩展 | DocService 加：sort/filter 多条件、批量更新、书签、阅读会话记录（docs/readlog.md） |
| D2 阅读统计服务 | ReadingStats（读会话时长/页数/日历聚合） |
| D3 check 扩展 | 书签指向行号越界、readlog 一致性 |
| D4 单测 | 每分支对应测试（DocService 批量/书签/统计） |

## 五、推荐组合与顺序

**首选组合：A + B + C + D（全做，≈2 周）**，顺序：
1. **D（支撑层先做）**：DocService 扩展 + 阅读统计 + 单测 —— 一切的地基
2. **A（管理）**：文档库三栏页（导航/表格/详情）+ 批量 —— 管理 GUI 感
3. **B（阅读）**：内置阅读视图 + 自动进度 + 书签/TOC + 统计 —— 阅读 GUI 感
4. **C（体验）**：全局搜索 + 命令面板 + 状态栏 —— 收尾打磨

**精简组合（若想先见效）：A + D（1 周）** → 管理先达到 Zotero 级；阅读仍靠外部阅读器（进度手动）。

**验收标准（"完美取代 GUI"定义）**：
- 管理：找文档、看详情、改状态/标签、批量操作、搜索 —— 全键盘 10 秒内完成
- 阅读：内置读文本、自动进度续读、书签跳转、TOC、周统计 —— 不再需要打开 GUI 阅读器
- 一切在终端完成；外部阅读器（zathura/foliate）保留为"精读 PDF/漫画"的增强选项
