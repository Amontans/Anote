# Anote 功能路线图（ROADMAP）

> 原则：每个版本先回答"价值 vs 维护成本"；**数据格式永远不破坏**（冻结层见 INTERFACES）。
> 参考成熟软件：Pi（对话/技能/MCP）、Obsidian（双链/图谱/模板/插件）、Joplin/Logseq（标签/搜索/日记）。

## 已实现（v0.8-dev）
- 纯 TEX 资产 + git 版本化；三级管线（src → memory/books）
- 语义检索（bge-small-zh 向量缓存）；关键词检索（rg 片段）
- 教科书工作流（ctexbook）；待读队列；记忆层；自检雷达；周回顾
- **TUI**（8 屏 + 命令面板 + 新手引导 + 数据迁移向导含 .git 随迁）
- **统一入口 `anote <command>`**；`anote stats` 文件统计

## 优先级排序（建议执行顺序）

1. **v1.1 的 AI 问答面板**（价值最高，与你的 DeepSeek 使用闭环）
2. **v0.9 标签 + 全文搜索**（检索体验立竿见影）
3. **v1.2 插件机制 + MCP**（让外部 AI 工具复用 anote）
4. 其余按需

## 铁律（任何版本不得违反）
- `src/` 笔记格式、META 契约、memory/ 结构 = 冻结层，永不破坏
- 新功能默认"纯新增"：派生物可重建、参数带默认值
- 每个功能必须配套：文档（INTERFACES/ROADMAP 更新）+ 测试 + CHANGELOG


## 长期发展方向（项目愿景）

### 短期（v1.3 → v1.4）
- v1.3 多端：Web 只读外壳、移动端阅读、自动提交定时器
- v1.4 体验：主题系统、知识图谱视图、周报自动生成

### 中期
- **知识编译层**（LLM Wiki 范式落地）：wiki.py 把 src/ 笔记自动编译成学科主题页（L1），与 memory（L2/L3）构成三层知识——"散点笔记 → 结构化知识"
- **反链图谱可视化**：概念 ← 引用关系图（META 标签 + 反链数据已有，补渲染）
- **插件生态成长**：随 CODING.md 规范沉淀社区插件

### 长期愿景：个人科研操作系统
- 本地优先 · 纯文本 · AI 编排 · 可插拔；任何工具可替换，数据永远是你的
- **与 Pi 深度互操作**：MCP 已打通（Pi 可直接驱动 anote）；AI 层保持"经 Pi 代理"模式
- 可发布为**开源通用工具**（MIT，学术界可复用）
- 不变铁律：冻结层永不破坏、低维护优先、测试门禁

### 优化方向（持续）
- 大库性能：语义索引分块/并行嵌入；搜索结果分页
- 备份自动化：定时自动 push + 异机冷备脚本
- 错误体验：统一 cli.run 已就位，持续收敛各命令的错误路径
